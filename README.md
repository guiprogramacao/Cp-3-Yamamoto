# Descrição do Sistema

O projeto consiste no desenvolvimento de um sistema ATM (Caixa Eletrônico) utilizando a linguagem C.

O sistema foi desenvolvido com o objetivo de aplicar conceitos fundamentais de programação estruturada, incluindo:
- Estruturas de repetição;
- Estruturas de decisão;
- Modularização com funções;
- Validação de dados;
- Controle de fluxo.

O ATM funciona via terminal/console e permanece em execução até que o usuário escolha a opção de saída.

---

# Funcionalidades Implementadas

- Consultar saldo;
- Realizar saque;
- Realizar depósito;
- Validação de saldo insuficiente;
- Validação de valores inválidos;
- Limite diário de saque;
- Menu interativo com loop contínuo;
- Limpeza de tela no console;
- Mensagens de feedback para o usuário.
